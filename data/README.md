# Data Directory

Stores training data and live collected sensor readings.

## Files

| File | Description | Generated By |
|---|---|---|
| `training_data.csv` | Synthetic labelled training data (4 sensors + status) | `scripts/generate_training_data.py` |
| `live_readings.csv` | Real-time readings collected from MQTT | `scripts/collect_mqtt_to_csv.py` |
| `live_alerts.csv` | AI-generated alerts from inference | `scripts/run_inference_subscriber.py` |

## Training Data Schema

```csv
machine_code,timestamp,temperature,vibration,current,rpm,status
CNC-001,2026-05-13T08:00:00.000Z,45.2,2.1,8.0,1500,normal
```

| Column | Type | Description |
|---|---|---|
| `machine_code` | string | Machine identifier (e.g. `CNC-001`) |
| `timestamp` | ISO 8601 | Reading timestamp |
| `temperature` | float | Temperature in °C |
| `vibration` | float | Vibration in mm/s |
| `current` | float | Electrical current in A |
| `rpm` | float | Rotational speed in RPM |
| `status` | string | Label: `normal`, `degradation`, `anomaly`, `failure` |
