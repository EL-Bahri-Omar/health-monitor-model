# Reports Directory

Stores model training reports and data quality analysis. These files are regenerated each time you retrain the models.

## Files

| File | Generated By | Description |
|---|---|---|
| `model_report.md` | `scripts/train_models.py` | Human-readable training report (accuracy, F1, confusion matrix) |
| `training_feature_windows.csv` | `scripts/train_models.py` | Feature table used for training |
| `reliability_report.json` | `scripts/reliability_report.py` | Data quality and completeness analysis |
