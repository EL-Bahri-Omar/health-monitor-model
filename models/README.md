# Models Directory

Stores trained model artifacts. These files are generated by `scripts/train_models.py` and should **not** be committed from untrusted sources — always retrain from your own data.

## Files

| File | Description |
|---|---|
| `fault_classifier.joblib` | RandomForest classifier (4-class: normal/degradation/anomaly/failure) |
| `anomaly_detector.joblib` | IsolationForest anomaly detector (trained on "normal" data) |
| `model_metadata.json` | Feature column names, window config, and label list |
| `metrics.json` | Accuracy, F1, confusion matrix from last training run |

## Retraining

```bash
python scripts/generate_training_data.py --output data/training_data.csv --rows 12000
python scripts/train_models.py --input data/training_data.csv --model-dir models
```

The training script overwrites existing model files in this directory.

## Security Note

`.joblib` files can execute arbitrary code when loaded. Only use model files that you trained yourself from the scripts in this repository.
